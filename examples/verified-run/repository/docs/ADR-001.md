# ADR-001: Subscription sandbox API

Status: accepted for trusted demonstration only.

## Decision

HTTPServer adapter → SubscriptionService → SQLite.

Use integer cents, a unique (customer_id, idempotency_key) constraint, and SQL parameters.

## Alternatives

PostgreSQL for concurrent production workloads; excluded from this local fixture.

## Tradeoffs

Single-process demonstration; no payments, OIDC, network sandbox, or production release.

X-Customer-Id is an explicitly spoofable sandbox identity, not authentication.
